
# Frequently Asked Questions

## 1. What is GitHub Pages?

GitHub Pages is a service used to host static websites directly from a GitHub repository.

## 2. What is Markdown?

Markdown is a lightweight markup language used to format documentation.

## 3. What is the docs folder?

The docs folder stores the documentation files used by GitHub Pages.

## 4. Can we connect multiple pages?

Yes. We can connect multiple Markdown pages using internal links.
